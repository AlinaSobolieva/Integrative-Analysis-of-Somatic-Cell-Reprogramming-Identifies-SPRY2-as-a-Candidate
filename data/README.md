# Data Description

This directory contains metadata and links to the datasets used in the analysis.

## Dataset Information
- **Source**: Gene Expression Omnibus (GEO)
- **Accession**: GSE90894 (subseries of GSE90895)
- **Organism**: *Mus musculus*
- **Experimental Groups**:
  - MEF (Mouse Embryonic Fibroblasts)
  - 48h (48 hours OSKM induction)
  - pre-iPSC (Intermediate pre-iPSCs)
  - ESC (Embryonic Stem Cells)
