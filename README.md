# Integrative-Analysis-of-Somatic-Cell-Reprogramming-Identifies-SPRY2-as-a-Candidate
Reproducible R-based integrative transcriptomic and network analysis of somatic cell reprogramming toward pluripotency. The project characterizes stage-specific transcriptional remodeling from MEFs to ESCs and investigates SPRY2 as an exploratory candidate associated with cellular plasticity and pluripotency.
